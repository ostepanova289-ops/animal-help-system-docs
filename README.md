# Техническая документация проекта

## О проекте
Документация информационной системы координации помощи бездомным животным.

## Подход
Документация оформлена в формате Markdown в рамках подхода docs-as-code.

## Структура документации
- Концепция системы
- Требования
- Модель данных
- API
- Архитектура
- Frontend
- Асинхронное взаимодействие
- Управление и роли
- Шаблоны недостающих артефактов

## Как использовать
Документация хранится в репозитории и может обновляться через Git.
